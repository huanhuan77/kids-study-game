# 📚 闯关复习大作战

二年级和六年级闯关复习游戏 APP，单页 HTML 应用，无需任何后端。

## 🎮 功能

- **二年级**：语文、数学（共 40 关）
- **六年级**：语文、数学、英语（共 60 关）
- 每关 6 题，60% 通过率 / 70% 两星 / 90% 三星
- 答题后立即显示正确答案与详细解析
- 连击奖励加分（最高 +10）
- 上一题回看功能
- localStorage 自动保存进度

## 🚀 使用方式

直接打开 `index.html` 即可在浏览器中运行（推荐手机/平板访问）。
